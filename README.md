# 50 sources de Python da CodeNomad Academy

Este repositório reúne 50 programas completos em Python, cada um num único arquivo, prontos para rodar e explicados linha a linha. Ele serve para quem está aprendendo Python e quer ler código de verdade, e para quem já programa e quer uma calculadora, um validador, um organizador de pastas ou um jogo de terminal sem instalar nada. Cada source faz uma coisa bem definida, valida a entrada, dá mensagens de erro claras e termina com três exercícios para você continuar. É um projeto da [CodeNomad Academy](https://codenomad.org), plataforma de autoestudo em desenvolvimento de software.

## Como rodar

Requisito: Python 3.10 ou mais novo. Nada além da biblioteca padrão. Não há `pip install`, não há `requirements.txt`.

Rodar uma source com argumentos reais:

```bash
python sources/01_calculadora_juros_compostos.py --capital 1000 --taxa 0.8 --meses 24 --aporte 200
```

Rodar a demonstração de qualquer source:

```bash
python sources/01_calculadora_juros_compostos.py --demo
```

A flag `--demo` executa uma demonstração completa com dados de exemplo, sem pedir nada no teclado e sem acessar a internet. Ela termina sozinha em poucos segundos e é o jeito mais rápido de ver o que o programa faz antes de ler o código.

Sem argumento nenhum, o programa mostra o uso (`--help` também funciona). Os jogos, sem argumentos, entram no modo interativo.

## Como este material é organizado

Um arquivo por programa. Cada source vive em `sources/NN_nome.py`, em que `NN` é o número de 01 a 50. Não há módulos compartilhados: você copia um arquivo e ele funciona sozinho.

Cabeçalho padrão. Todo arquivo começa com o mesmo bloco de comentário, com cinco campos: "O que faz", "Como usar" (o comando real e o comando com `--demo`), "O que você aprende", "Requisitos" e a licença. Dá para saber se a source serve antes de rolar a tela.

Comentários onde importa. Os comentários estão nos pontos em que um aluno costuma tropeçar: por que dinheiro se calcula em centavos inteiros, por que a busca binária exige vetor ordenado, por que a recursão pura de Fibonacci explode. O resto do código fala por si.

Bloco "Para ir além". Cada arquivo termina com três exercícios sugeridos para você estender o programa com o que acabou de ler.

Só biblioteca padrão. Os 50 arquivos usam apenas o que vem com o Python: `argparse`, `pathlib`, `dataclasses`, `json`, `csv`, `statistics`, `datetime`, `hashlib`, `http.server`, `urllib` e companhia. Isso é de propósito: você aprende a linguagem, não um framework.

Dois modos em toda source. Com argumentos, o programa faz o trabalho de verdade. Com `--demo`, ele mostra tudo o que sabe fazer sem depender de você.
